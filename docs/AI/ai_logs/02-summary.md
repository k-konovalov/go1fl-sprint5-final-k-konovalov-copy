# Сессия 02 — 2026-11-17

## Тема
Реализация методов `Parse` и `ActionInfo` в пакете `trainings` (фитнес-трекер, Go).

## Вопросы пользователя
- Как разделить строку на слайсы в Go?
- Как узнать длину строки?
- Как проверить через руны, а не юникод?
- Как преобразовать строку в int?
- Почему не срабатывают `go test ./internal/trainings`?
- Выгрузка чата через скилл chat-log.

## Ответы/советы тьютора
- Для разделения строки использовать `strings.SplitN(datastring, ",", 3)` — подходит для CSV-формата.
- `len(string)` — байтовая длина (O(1)), `len([]rune(s))` — длина в символах (O(n), аллокация). Для парсера достаточно `len(string)`.
- `strconv.Atoi` — стандартный способ парсинга int из строки, поддерживает `+` префикс.
- Ошибка `index out of range [3] with length 3` — обращение к `slice[3]` вместо `slice[2]`.
- В `ActionInfo` — конвертация `float64` в `string` через `strconv.FormatFloat`, а потом использование `%f` в `fmt.Sprintf` вызывает `%!f(string=...)`. Нужно передавать `float64` напрямую или использовать `%s`.
- Лишний пробел в `"Длительность:  %s"` (два пробела) вместо `"Длительность: %s"` (один пробел) — все тесты `TestActionInfo` падали из-за этого.
- `default` кейс в `switch` по типу тренировки должен возвращать ошибку для неизвестных типов.

## Прогресс
- `Parse` реализован: парсинг CSV-строки, валидация шагов и длительности.
- `ActionInfo` реализован: расчёт дистанции, скорости, калорий для "Бега" и "Ходьбы".
