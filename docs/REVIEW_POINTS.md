# Критерии оценивания ревью

## 1. Использовать базовый синтаксис Go — 0/2

| Балл | Описание |
| ---- | -------- |
| 0 | Навык не проявлен или проявлен с критическими ошибками. Требуется значительная доработка, обязательна ещё одна итерация ревью. |
| 1 | Навык проявлен частично, требуется доработка и ещё одна итерация ревью. |
| 2 | См. чек-лист ниже. |

### Чек-лист (2 балла)

- При парсинге входных данных строка делится на слайс строк с последующей проверкой количества элементов слайса.
- Обеспечивается обработка ошибок с их возвратом в необходимых случаях.
- Реализована обработка крайних случаев.
- Применяется стандартная библиотека языка.
- Используются условные конструкции `switch` и `if`.
- Обеспечивается разделение строки на слайс строк.
- Реализованы методы для всех типов:
  - `personaldata`;
  - `trainings`;
  - `daysteps`.
- Использован эмбеддинг и интерфейс `actioninfo`, через который осуществляется полиморфизм.
- Указатели используются при передаче и работе с данными, где это необходимо.
